# Fraud Detection

Detects fraudulent transactions in a highly imbalanced dataset (about 1% fraud) using a class-weighted Random Forest and decision-threshold tuning.

## What you'll learn

- Why accuracy misleads on imbalanced data
- Class weights
- Precision-recall curves and threshold tuning

## How to run

```bash
git clone https://github.com/Ddharsh1707/fraud-detection.git
cd fraud-detection
pip install -r requirements.txt
python main.py
```

No dataset download needed: the data is built into scikit-learn or generated by the script.
